# Indian Sign Language (ISL) Real-Time Translator
**Team Name:** TEAM RUDRASTRA | **Team ID:** TEAM-5B433B

## Overview
A real-time Computer Vision and Machine Learning prototype to bridge the communication gap for hearing-impaired individuals by translating ISL hand gestures into text and real-time speech.

## Features
- Real-time gesture recognition via Webcam
- Machine Learning classification (Random Forest Classifier)
- Instant Text-to-Speech audio feedback (pyttsx3)

## Tech Stack
- Python
- OpenCV
- Scikit-learn
- NumPy
- pyttsx3

## How to Run
1. Install dependencies:
   pip install opencv-python scikit-learn numpy pyttsx3

2. Run live translator:
   python 3_realtime_test.py
